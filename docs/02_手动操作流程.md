# 手动操作流程

## 1. 启动统一控制台

在 Windows 资源管理器中，直接双击运行：

`启动Codex清理工具.cmd`

程序启动时默认进入只读模式。即使 Codex 正在运行，也可以随时安全浏览所有项目与会话清单。

## 2. 浏览与只读健康审计

1. 输入 `2`：树状展开全机所有本地项目及关联会话，查看各个会话的状态标签（如 `[正常完整]`、`【幽灵残留】`、`[云端同步]` 等）。
2. 输入 `3`：输入指定会话序号，查看该会话在 `codex-dev.db`、`state_5.sqlite` 及物理文件的全量证据。
3. 输入 `7`：一键执行 SQLite 数据库的只读 quick_check 健康诊断。

## 3. 正式清理前准备

如果需要执行删除操作（清理幽灵残留或勾选删除特定会话）：

1. 保存所有需要保留的 Codex 工作；
2. 关闭 Codex 主窗口；
3. 检查系统托盘，右键选择“退出”或“Quit”，确保后台辅助进程完全退出。

若系统检测到后台仍在运行，程序会自动阻断写入操作并列出占用进程。

## 4. 执行清理

1. **一键清理幽灵**：输入 `4`，程序自动筛选出所有无物理正文的失效侧边栏条目，生成 Dry-run 预审清单。
2. **勾选指定会话删除**：输入 `5`，输入要删除的会话编号（支持如 `1,3` 或区间 `2-4`）。
3. 核对 Dry-run 执行计划（目标数量、涉及数据库、备份位置与操作码）。
4. 按照屏幕提示精确输入带操作码的安全确认短语（例如：`确认删除3个本机会话 A7C19E2B`）。
5. 程序自动执行快照冷备份、同卷物理隔离与分库级联事务清理。

## 5. 清理后验证

1. 程序执行完毕后自动刷新扫描，确认目标条目已清零；
2. 重新启动 Codex 桌面客户端，检查侧边栏无效条目已消失，有效任务依然完好。
